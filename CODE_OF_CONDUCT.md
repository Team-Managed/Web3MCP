# Code of conduct

We want Web3MCP discussions to be welcoming and technically useful. Be respectful, assume good faith, critique ideas and code rather than people, and make room for contributors with different levels of experience. Harassment, threats, discrimination, and disclosure of private information are not acceptable.

Project maintainers may remove harmful content or restrict participation. Report conduct concerns privately to a repository maintainer through their GitHub profile. For security vulnerabilities, use the separate [security reporting process](SECURITY.md). Maintainers will review conduct reports discreetly and take appropriate action.
