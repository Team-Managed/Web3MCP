# Protocol

This directory will hold the normative Web3MCP v0.1 manifest schema, account layout, encoding rules, fixtures, and conformance vectors. The current [project design](../docs/superpowers/specs/2026-10-13-web3mcp-project-design.md) is a proposal; no wire format has been frozen or published yet.

The first profile is Anchor-compatible and discovers a target program from its program ID. SNS support is deferred.
